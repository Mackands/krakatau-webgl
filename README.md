# Mount Krakatau Eruption

A low-poly volcanic eruption built with Unity 6000.3.12f1 for WebGL.

This repository contains the browser build. Unity and Blender source files are maintained in a separate private repository.

## Controls

- Space, click or tap: restart the eruption.
- Drag: orbit the island.
- H: toggle performance information.

## Run locally

Serve this folder over HTTP, for example with `python -m http.server 8080`, then open `http://localhost:8080`.

The build uses Unity's Gzip fallback loader and can run on GitHub Pages.
